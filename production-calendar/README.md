# TYPE-A Production Calendar · Aug–Oct 2026

Production calendar across four strands: Ogilvy/WPP (Google Pixel 11), Vayner
(Indeed), Re:act (BOOST Ireland) and TYPE-A direct (Halima).

Published as a design canvas:
https://claude.ai/code/artifact/9e8e97d8-544a-4e9a-823f-6ce49ee4fda0

## Files

- `Main.dc.html` — overview and key (generated by hand)
- `August/September/October.dc.html` — month grids, generated from `months.mjs`
- `Tracker.dc.html` — asset tracker, generated from `sheets.mjs`
- `Capacity.dc.html` — day accounting and open questions (generated by hand)
- `build.mjs` — theme, components and the month-grid renderer
- `months.mjs` — the schedule data; edit here, then `node months.mjs`
- `sheets.mjs` — the tracker data; edit here, then `node sheets.mjs`
- `canvas.json` — artboard layout on the canvas

## Regenerating

```bash
node months.mjs && node sheets.mjs
```

Then re-seed and republish the canvas.

## Conventions

- Day cell colour = production stage (build, shoot, edit, feedback, live)
- Pill colour = company; chip on the pill = owner
- Solid pill outline = date fixed in a diary, client deck or proposal
- Dashed pill outline = proposed, safe to move
- Hatched cell = Anaïs unavailable

`F2` and `F3` are unassigned collaborator slots pending real names.
